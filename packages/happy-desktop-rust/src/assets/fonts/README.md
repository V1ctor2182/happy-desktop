# Bundled fonts

- `Figtree-Variable.woff2` is Figtree variable 5.2.10 from Fontsource.
- `JetBrainsMono-Variable.woff2` is JetBrains Mono variable 5.2.8 from
  Fontsource.

Both are the exact Latin font assets used by `happy-desktop-ui` and are bundled
here so the native app builds independently of Node dependencies. Both font
families are licensed under the SIL Open Font License 1.1.
